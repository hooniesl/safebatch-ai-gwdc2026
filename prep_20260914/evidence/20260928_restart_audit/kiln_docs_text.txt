Kiln — AI inference API on NPUs
Call AI models with the OpenAI SDK. Set base_url and an API key to start.
Get an API key
Point your OpenAI SDK at Kiln.
Point base_url at Kiln and use an API key that starts with sk-bk-…. Put your key in the examples below, then run them. Some parameters are not supported yet; see Known limitations in the API reference.
